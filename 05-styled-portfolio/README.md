# Design Choices - Umair Beg

**Fonts:**
- Headings: Poppins (Bold, modern, good for portfolio titles)
- Body: Inter (Clean, highly readable for long text)
Pairing is professional and used by top tech portfolios.

**Color Palette (4 colors):**
- Primary #0f172a (Slate 900) - Trust, professional header/footer
- Secondary #3b82f6 (Blue) - CTA, links, tech feeling
- Accent #f59e0b (Amber) - Highlight logo, makes portfolio warm
- Background #f8fafc (Light slate) - Clean, not pure white, easy on eyes

**Tokens:** All colors, spacing, fonts in :root for easy change.
**Selectors Used:** element (body,h2), class (.card,.logo), id (#main-header), descendant (nav ul li a), pseudo-class (:hover)
